# BZEAD UK iOS

Native SwiftUI app targeting iOS 16 and later.

This is an initial scaffold with the splash screen and a Home placeholder.
The remaining screens and backend integrations are not implemented yet.

Open `BZEAD.xcodeproj` in Xcode on a Mac. Set a valid bundle identifier and
signing team before running on a device or distributing the app. The current
bundle identifier is a placeholder.

The separate Android and web source repository is the implementation reference.
No server secrets should be included in this app.
